## Agent skills

### Issue tracker

Issues are tracked using local markdown files in the `.scratch/` directory. See `docs/agents/issue-tracker.md`.

### Triage labels

Using standard default string mapping (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout with a global `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
